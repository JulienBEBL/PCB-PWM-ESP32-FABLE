# PCB-PWM-ESP32-FABLE

Carte de sécurité BEBL : lecture d'une consigne PWM, machine d'états, pilotage d'un vérin Actuonix L12 12 V par 2 relais DPDT. MCU : carte de dev ESP32-S3-DevKitC-1-N8 enfichée. Carte jumelle de la carte STM32.
